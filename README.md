# Battle of Brains 2026 🧠💻

Welcome to the official repository for **Battle of Brains 2026**! 

This programming contest was carefully designed to test the problem-solving skills, algorithmic thinking, and coding proficiency of the participants. To ensure a great learning experience, this repository contains the complete problemset, detailed editorials (including logic and complexity analysis), and the official C++ solution codes. 

Whether you are a participant looking to upsolve or a competitive programming enthusiast practicing new concepts, we hope you find these resources helpful!

---

## 📌 Contest Information

* **Event Name:** Battle of Brains 2026
* **Organized by:** Programming Club of IST
* **Sponsored by:** Shafar Foundation
* **Date:** 17 August 2026
* **Total Problems:** 10
* **Difficulty Range:** 800 - 2100 (Codeforces Rating Scale)
